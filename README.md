# Quantum Neural Chain — Джарвис 8.2

Квантовая память с затуханием, троичной логикой C₁₂₃ и запутанностью между фактами.

## Идея

Факты хранятся как **квантовые нейроны** (2-кубитные состояния).
Связанные факты **запутываются** — при поиске запутанные нейроны усиливают
друг друга через квантовый резонанс. Старые связи ослабевают (затухание).

- **Триты C₁₂₃** — три состояния вместо двух: да / нет / неизвестно
- **Квантовое состояние** — 2 кубита, 4 амплитуды, гейты H/CNOT/Pauli
- **Запутанность** — граф связей между фактами, кластеризация
- **Резонанс** — влияние нейронов друг на друга при поиске
- **Затухание** — старые факты забываются, если не подтверждаются

## Стек

- Python 3.10+
- numpy — квантовые состояния и матрицы плотности
- websockets — WebSocket-сервер
- HTML/CSS/JS — веб-интерфейс чата

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

1. Запусти WebSocket-сервер:
   ```bash
   python -m api.websocket_server
   ```
2. Открой `frontend/public/index.html` в браузере
3. Пиши в чат — Джарвис отвечает через квантовый поиск

### Команды в чате

| Команда | Что делает |
|---------|-----------|
| `/stats` | Статистика памяти |
| `/facts` | Список фактов |
| `/entanglements` | Список запутанных пар |
| `/remember вопрос → ответ` | Запомнить факт |
| `/entangle факт1 ↔ факт2` | Запутать два факта |
| `/measure факт` | Измерить факт |
| `/help` | Все команды |

## Структура

| Папка / файл | Назначение |
|--------------|-----------|
| `core/` | Квантовое состояние, нейрон, запутанность |
| `memory/` | Высокоуровневая память: remember/recall/forget |
| `api/` | WebSocket-сервер |
| `frontend/` | Веб-интерфейс чата |
| `network/` | Сетевой слой (в разработке) |
| `blockchain/` | Блокчейн-компонент (в разработке) |
| `learning/` | Модуль обучения (в разработке) |
| `scripts/` | Утилиты |
| `tests/` | Тесты |
| `data/` | Данные проекта |
